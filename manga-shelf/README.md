# Полка манги

Страница с мангой в виде 3D-обложек на тёмно-бордовой «стене». Сделана по разбору вертикального видео с полкой книг, пластинок и игр.

- При наведении курсора или касании карточка наклоняется вслед за ним, выдвигается вперёд, по обложке бежит блик.
- В углу карточки оценка со звездой (по 10-балльной шкале).
- По клику открывается окно с описанием: автор, годы, число томов, статус, жанр и краткий сюжет. Закрывается крестиком, клавишей Esc или кликом по фону.

Сейчас на полке четыре манги: One Piece, Bleach, Dr. Stone, Naruto.

## Как открыть

Открой `index.html` в браузере. Сборка не нужна: только HTML, CSS и JS, шрифты грузятся с Google Fonts.

## Как добавить мангу

Добавь запись в массив `MANGA` в скрипте внизу `index.html` и, при желании, свой стиль обложки `.c-<id>` в CSS и рисунок в `ART`.

Обложки нарисованы стилизованно, без официальных артов издателей: официальные обложки защищены авторским правом.
