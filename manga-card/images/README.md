# Обложки

Сейчас здесь лежат заглушки. Чтобы поставить настоящую обложку, замени файл файлом с тем же именем, код менять не нужно.

| Манга | Обычная плотность (320×480) | Двойная плотность (640×960) |
| --- | --- | --- |
| One Piece | `one-piece.jpg` | `one-piece@2x.jpg` |
| Bleach | `bleach.jpg` | `bleach@2x.jpg` |
| Dr. Stone | `dr-stone.jpg` | `dr-stone@2x.jpg` |
| Naruto | `naruto.jpg` | `naruto@2x.jpg` |

- Пропорции 2:3. Если пропорции другие, обложка обрежется по краям, но не растянется.
- Если файла нет, на полке появится серая заглушка с названием.
- Официальные обложки защищены авторским правом издателя. Перед публикацией проверь, что у тебя есть право их использовать.
